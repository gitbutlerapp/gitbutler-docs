---
title: "`but diff`"
description: "Show the diff of changes in the repo."
---

Without any arguments, it shows the diff of all uncommitted changes of the checkout `but` runs
in: the main worktree's, or a linked worktree's when run from inside one. Optionally, provide one
CLI ID to show the diff for an uncommitted file, branch, commit, committed file, or worktree.

`TARGET` accepts at most one entity. To show several entities, run this command once per entity.

**Usage:** `but diff [TARGET]`

## Arguments

* `<TARGET>` — What to diff, by CLI ID: a commit, branch, committed file or hunk, uncommitted file or hunk, path prefix ending in /, or a worktree's uncommitted area. A commit lists its files and hunks with their IDs.

If omitted shows the diff of all uncommitted changes of the checkout but runs in, with file and hunk IDs.

For more details about CLI IDs, see but help cli-ids.
