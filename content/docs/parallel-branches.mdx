---
title: Parallel Branches
description: Work on several branches in one folder with one editor window, without switching branches or creating worktrees.
---

You don't switch branches, and you don't need a folder per branch.
All the branches you're working on are **in the same folder at the same time**, so you open one editor window on the repository.
When you commit, you choose which branch each change goes to.

## What is in your folder

Your folder contains the changes from all your branches, combined.
For example, with two branches, `but status` shows each branch and its commits:

```example parallel-branches-but-status-1
but status
```

Git sees this combination as a single merge commit on a branch called [`gitbutler/workspace`](/workspace-branch), so your editor and other Git tools work as usual.

```example parallel-branches-git-log-1
git log --oneline --graph
```

## Check each branch's changes

To see only one branch's changes, pass its name to `but diff`:

```example parallel-branches-but-diff-1
but diff user-bookmarks
```

```example parallel-branches-but-diff-2
but diff liked-tweets
```

## Hide a branch

To take a branch's changes out of your folder, unapply it:

```example parallel-branches-but-unapply-1
but unapply liked-tweets
```

`but status` now shows only `user-bookmarks`:

```example parallel-branches-but-status-2
but status
```

The workspace commit now sits on top of `user-bookmarks` alone:

```example parallel-branches-git-log-2
git log --oneline --graph
```

`liked-tweets` still exists, and `but branch` lists it under unapplied branches:

```example parallel-branches-but-branch-1
but branch
```

To bring the branch back, apply it:

```example parallel-branches-but-apply-1
but apply liked-tweets
```

## Run several agents at once

You can run several agent sessions in the same folder, and each session commits the changes it made to a separate branch.
There is **nothing to set up per session**: once your agents use GitButler, start another session in the same folder.
[Parallel agents](/ai-agents/parallel-agents) explains how.
