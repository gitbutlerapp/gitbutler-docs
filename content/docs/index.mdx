## Overview

GitButler is a version control tool built on Git. It lets you work on several branches at once in one folder, and it works in any Git repository with no setup. Our focus is everything after writing code in your editor and before sharing it on GitHub.

The [desktop app](/overview), the [CLI](/cli-overview), and the [terminal UI](/gitbutler-tui) all work on the same repository state, and coding agents can use GitButler through the CLI.

## What We Do

With GitButler you can work on several branches at once, run several coding agents in one folder, and edit, reorder, or split commits without an interactive rebase. When a rebase hits a conflict, GitButler marks the conflicted commits and keeps going, and you resolve them one at a time. It records every operation, so you can undo any of them.
